## 🌟 Key Features

1. **Gym Floor Crowd Tracker**:
   - Hour-by-hour crowd density estimation (6:00 AM – 10:00 PM) to help members plan distraction-free lifting sessions.
   - Real-time indicator syncing with Indian Standard Time (IST).

2. **Custom Plan & Cost Builder**:
   - Dynamic membership tier calculator (1, 3, 6, 12 months) with duration discounts.
   - Add-on selection (Personal Trainer, Diet Chart, Cardio Access) with real-time per-day pricing estimates.

3. **Built-in Powerlifting & Fitness Calculators**:
   - **BMI & Macro Target Calculator**: Calculates maintenance calories, activity expenditure, and daily protein targets.
   - **Barbell Plate Loading Calculator**: Visualizes exact Olympic bumper plates (25kg, 20kg, 15kg, 10kg, 5kg, 2.5kg, 1.25kg) needed per side on a 20kg barbell.
   - **Rest Interval Timer**: Quick 30s, 60s, 90s, 120s rest interval timers with haptic vibration alerts.
   - **1-Rep Max (1RM) Estimator**: Calculates maximum single-rep lift capacity using the Epley formula.

4. **Interactive Workout Split Tracker**:
   - Pre-loaded splits: *Push*, *Pull*, *Legs*, *Full Body*, and *Beginner*.
   - Check off exercises during workouts with persistent local storage saving and animated radial progress ring.

5. **Location & Direct Connectivity**:
   - Metro connectivity guide (Nearest Metro: **Dashrath Puri**).
   - One-tap Google Maps directions, phone calling (`097178 08212`), and Google Reviews integration.

6. **Free Trial WhatsApp Booking**:
   - Interactive booking form that dynamically opens WhatsApp pre-populated with member name, goal, preferred time slot, and chosen membership plan.

7. **Aesthetics & Design System**:
   - Custom warm cream / ecru palette (`#EAE6DA`) with industrial brutalist borders, tactile SVG textures, and antique gold accents (`#B8860B`).
   - One-click Light / Dark mode toggle.
   - High-contrast typography featuring *Anton*, *Inter Tight*, and *JetBrains Mono*.

## 🚀 Getting Started

Since this is a lightweight, zero-dependency static web application, no build steps are required.

### Run Locally
```bash
# Using Python
python -m http.server 3000

# Using Node.js npx serve
npx serve .
```
Then visit `http://localhost:3000` in any web browser.
